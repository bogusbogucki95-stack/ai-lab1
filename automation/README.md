# Automatyzacja AI LAB 2.1 — wersja demonstracyjna

GitHub Actions uruchamia kontrolę **przykładowych** zadań z pliku `tasks.example.json` co poniedziałek (UTC) lub ręcznie. Raport jest artefaktem wykonania workflow, nie jest publikowany w repozytorium.

**Ważne:** zadania w mobilnym panelu pozostają w localStorage telefonu. Automatyzacja ich nie widzi. Nie umieszczaj prywatnych danych w publicznym repozytorium.

Kolejny etap: prywatna baza danych, uwierzytelnianie i bezpieczny kanał synchronizacji. Nie włączaj płatnych usług bez zatwierdzenia budżetu.
